# 04 · 风险、测试矩阵与验收标准

## 1. 风险清单

| 编号 | 风险 | 影响 | 对策（必须实现） |
|---|---|---|---|
| **R1** | **授权缓存陈旧**：`sandbox-local` 按工作区缓存授权，命中后不复查 ACL；外部擦除后本实例仍发放写 SID | 受限写入静默失败，模型可能转而申请提权 | 擦除后**禁止本实例再 workspace-write**；默认引导"立即重启"；关闭流程把擦除排在退出之前 |
| **R2** | 其他活跃实例共享同一工作区 | 擦除后对方写入开始失败 | 列为 **X 类阻塞**，默认拒绝擦除；需用户先关闭对方 |
| **R3** | 常驻终端导致只读切换被拒 | 权限回收不完整 | 先关终端再切换；逐会话记录结果；失败必须让用户裁断 |
| **R4** | 版本耦合：座位名/API 在版本间变动 | 按钮消失或插件激活失败 | 座位与构建基线纳入 M0 Spike；宿主半与客户端半解耦；失败要"响亮"（激活失败即报错） |
| **R5** | 擦除部分失败（权限、文件锁、同步盘占用） | 残留 | 重试 + 台账 + 启动清扫；UI 明示"未完成" |
| **R6** | 关闭时未刷盘 | 会话丢失最后几步 | 退出前逐会话 flush，并在失败时告知 |
| **R7** | 目录不属于当前用户 / ACL 不可写 | 擦不掉 | probe 阶段判定 `ownedByMe`，不满足即 X 类 |
| **R8** | 误触 / CSRF | 意外擦除或关闭 | POST + nonce；二次确认；GET 只读 |
| **R9** | 大树代价误估 | 退出卡顿数秒 | 对话框显示按对象数估算的耗时；设超时预算 |
| **R10** | 强杀路径（任务管理器 / 断电） | 内部钩子全不执行 | 台账 + 启动清扫（唯一兜底） |
| **R11** | 擦除掉"用户自定义 ACE" | 破坏他人配置 | 只做 REVOKE/DENY 合并，禁止 `/reset`；只动三件对应的主体 |

## 2. 测试矩阵

| # | 场景 | 期望 |
|---|---|---|
| T1 | 干净实例（无活跃对话、单实例、单工作区） | 关闭：门禁通过；退出码 0；temp 目录消失；三件清空且校验通过 |
| T2 | 有进行中的回合 | 关闭/清理：弹窗列出"有正在跑的工作"，**再点一次即执行**（M6.1/M6.3 起不再要求勾选） |

| T5 | 两个实例共享同一工作区 | 任一按钮：报 X 类阻塞并终止擦除，给出"先关闭 PID …" |

| T7 | 工作区含 6 000 / 60 000 对象 | 对话框代价预估与实测偏差 < 50%；退出耗时可接受（< 3 s / < 15 s） |
| T8 | 擦除中途失败（人为占用/权限） | 台账出现 pending；UI 明示；下次启动清扫处理 |
| T9 | 直接强杀进程（不点按钮） | 下次启动清扫补擦；无遗漏 |
| T10 | 0.1.5-rc.3 实例（无三件） | probe 报"无需擦除"；按钮动作不报错 |
| T11 | 非 Windows / 权限不足 | 按钮禁用 + tooltip 说明 |
| T12 | 二次点击 / 并发点击 | 幂等；第二次进入"进行中"而非重复执行 |
